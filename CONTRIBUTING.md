# Contributing

This project is a **construction site**: contributions are welcome, but the
goal is to track experiments, not to deliver a finished product.

Before opening a PR:

1. Verify the behaviour is reproducible on Windows 11 x64 with
   `SeparateProcess=1` and a non-elevated Everything.
2. Always include the Windows / Explorer / Everything / mod and NSE versions
   you used.
3. Do not commit `mod/generated/`: it is generated by `mod\regenerate-winrt.ps1`
   and ignored by git (it is only needed for local builds).
4. If you touch the shell contract (`nse/`), also run `tests/run-mingw.ps1`.
5. Keep changes small and separate bug fixes from new features.

The most fragile and most useful areas to improve are listed in
[README.md](README.md) → *Known limitations / open issues*.

There is no full-time maintainer: PRs may stay open for a long time.
